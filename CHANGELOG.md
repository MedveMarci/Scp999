# Changelog

## [1.4.0]

### Added

- The built-in sounds are saved to `LabAPI/configs/Scp999/Audio/` on startup. Files already there are never overwritten,
  so a sound can be replaced by putting your own `.ogg` there with the same name.
- `audio_directory_path` config option to change where the sounds are saved and read from.

- Updated to the latest SecretLabNAudio. (2.1.2)
- Updated to the latest RoleAPI. (2.1.1)
